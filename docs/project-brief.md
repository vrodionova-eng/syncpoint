## Технические решения

## Ключевые сущности

- **Пространство** — кабинет, пост автомойки и т.п.
- **Рабочая точка** — то, что внутри пространства (несколько на пространство).
- **Инструмент** + **Экземпляр** — вид «Фен» и его конкретные физические штуки;
  у каждого экземпляра может быть своё пространство.
- **Услуга** — цена / диапазон / составная (из под-услуг); сумма авто / своя / при записи.
- **Сотрудник** — из Б24 (подтягивается) или добавленный вручную (только имя).
- **Запись** (Этап 2) — точка + время + участники + услуга(и) + экземпляры + клиент CRM.

## Расчёт ЗП (задел, реализация — Этап 2)

Схема настраивается в карточке сотрудника переключателем:
- **Общий процент** — фиксированный % от суммы любой записи;
- **Зависимость от услуги** — для каждой услуги свой %, у разных сотрудников
  по одной услуге % может отличаться.

В Этапе 1 — только поля в данных (`employee.salary`), без экрана настройки.

## Особенности проекта

- Хранилище — JSON-файлы. На проде каталог данных `/opt/data/` (переживает чистый деплой), локально `./data`. Путь через `DATA_DIR`.
- Термин для физической штуки инструмента — «Экземпляр» (не «бирка»/«единица»).
- Б24 шлёт `POST /` при открытии в iframe — сервер отвечает так же, как на `GET /` (отдаёт `index.html`).
